# Python Task 01

## Objective

This task focuses on understanding Python installation, environment setup, user input handling, arithmetic operations, and system information retrieval using Python programming.

The concepts covered in this task include:

* Variables
* User Input Handling
* Print Statements
* Arithmetic Operations
* Python Modules
* System Information Retrieval

---

## Programs Included

### 1. System Information (`system_info.py`)

This program displays personal information along with the current date and time.

Information displayed:

* Name
* College Name
* Branch
* Internship Name
* Current Date and Time

**Example Output:**

```text
Name: Priya Kumari
College: Kristu Jayanti Institute of Technology
Branch: MCA
Internship: Python Programming Internship
Date & Time: 2026-06-06 10:30:45
```

---

### 2. User Input Program (`user_input.py`)

This program accepts user details and displays them in a formatted manner.

Inputs:

* Name
* Age
* Favorite Technology

**Example Output:**

```text
Enter your name: Priya
Enter your age: 21
Enter your favorite technology: Python

Hello Priya!
You are 21 years old.
Your favorite technology is Python.
```

---

### 3. Basic Calculator (`calculator.py`)

This program performs basic arithmetic operations on two numbers.

Operations performed:

* Addition
* Subtraction
* Multiplication
* Division

**Example Output:**

```text
Enter First Number: 10
Enter Second Number: 5

Addition: 15
Subtraction: 5
Multiplication: 50
Division: 2
```

---

### 4. System Details (`system_details.py`)

This program displays information about the current computer system.

Information displayed:

* Operating System
* Username
* Current Working Directory
* Python Version

**Example Output:**

```text
Operating System: Windows
Username: Priya
Current Working Directory:
C:\Users\Priya\Desktop\Python_Task_01

Python Version:
3.13.0
```
